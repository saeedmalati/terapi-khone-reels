# terapi-khone-reels

Reels for the Instagram page terapi_khone.

- `template/` — HyperFrames reel template (1080×1920, Vazirmatn, write-on text, original synthesized music via `music.py <out.wav>`).
- `reels/` — published reel files (public URLs are used to publish via vidIQ).
- `log.json` — every published reel: topic, title, permalink. Never repeat a topic+angle already listed.
